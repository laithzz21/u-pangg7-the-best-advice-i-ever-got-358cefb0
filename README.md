One sentence, no longer than 200 characters, about the best advice the entrant ever received.

## Entry

> My grandma said if you can't say something nice, say it in a whisper so at least you sound mysterious.

## Run

```sh
python3 main.py
```

The program validates the entry (exactly one sentence, at most 200 characters), prints it to stdout, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `$MAKEFUN_OUTPUT`, or a per-entry path under `/tmp` if neither is set.
